# C5 Hunter

### C5助手 · Windows 桌面工具 · by lohick

集中管理 C5 商品规则、账户余额、订单与购买记录，让查询、筛选和操作更清晰。

## 功能概览

- **商品规则**：添加饰品 ID，设置和快捷调整最高购买价，管理多条规则。
- **购买模式**：支持模拟购买与 C5 OpenAPI 下单；真实可用功能取决于账户权限和平台状态。
- **Steam 账号**：读取并选择收货账号，本地缓存对应 Steam Trade URL 供 API 下单核对。
- **账户与订单**：读取余额和保证金，刷新最新订单或重新读取全部数据，按类型、状态和时间筛选。
- **饰品名称缓存**：本地保存饰品 ID 与名称，减少重复详情请求。
- **购买记录**：查看序列号、饰品 ID、购买时间、价格及平均购买价，支持手动清除。
- **运行日志**：区分成功、失败和待确认结果，日志由用户手动清理。
- **深色界面**：默认深色模式，可切换明亮模式。

## 下载与安装

1. 前往 [Releases](https://github.com/Xiazhi-Shought/C5-Hunter/releases/latest) 下载 `C5助手-v1.0.1-win-x64.zip`。
2. 将压缩包**完整解压**到独立、可写的文件夹。
3. 保留包内 DLL 与 `WebView2Runtime`，不要只复制 `C5助手.exe`。
4. 双击 `C5助手.exe` 启动。

发布包面向 **Windows x64**，随附 WebView2 运行时，因此体积较大。目前程序未添加发行者代码签名，Windows 可能显示“未知发布者”。请只从本项目 Releases 页面下载，并核对 SHA256。

## 初次使用

1. 在“登录 C5”页完成网页登录并采集必要 Cookie。
2. 在“App Key 与 Steam”页填写自己的 C5 AppKey，并按平台要求配置 IP 白名单。
3. 获取 Steam 账号，选择购买收货账号并刷新、核对对应交易链接。
4. 在“规则”页添加饰品 ID 和最高购买价。
5. 首次运行建议先勾选 **“启用模拟购买”** 测试规则。请注意：未勾选该项并不代表模拟模式。
6. **“使用 API 下单”默认勾选**；真实购买前请确认账户、余额、交易链接、价格上限及购买模式。

订单数据仅在用户点击对应刷新按钮时更新：

- **刷新订单与余额**：读取最新订单与余额。
- **刷新全部数据**：重新读取完整订单数据。

## 隐私与本地数据

C5助手不设置向开发者收集或上传用户隐私数据的功能，不会把 AppKey、Cookie、Steam 交易链接、账号、订单、购买记录或日志上传到 lohick 的服务器或本项目仓库。

用户配置、浏览器资料、订单缓存、饰品名称缓存、购买记录、待确认记录及日志默认保存在程序目录下的 `用户数据` 文件夹。敏感配置使用 Windows 当前用户加密机制保存；部分缓存和日志属于普通本地文件，可能包含账号或交易信息。

- 请勿公开或上传自己的 `用户数据` 文件夹。
- 请勿在 Issues、截图或日志中暴露 AppKey、Cookie、完整交易链接或未脱敏订单。
- 登录、查询、读取余额或订单、提交购买时，软件仍需向 C5 页面或接口发送完成操作所需的数据。
- “读取本机公网 IP”会访问 `api.ipify.org`；点击项目链接会访问 GitHub。
- 删除本地数据不会取消平台已受理的订单，也不会删除平台服务器上的记录。
