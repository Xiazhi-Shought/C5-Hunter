# C5 Hunter

### Windows 桌面助手 · by lohick

集中管理 C5 商品规则、账户余额与订单，让操作和记录更清晰。

[版本下载](https://github.com/Xiazhi-Shought/C5-Hunter/releases) · [问题反馈](https://github.com/Xiazhi-Shought/C5-Hunter/issues) · [作者主页](https://github.com/Xiazhi-Shought)

> **发布准备中**：目前仅建立项目介绍页，尚未上传公开下载包。后续程序及更新说明将在 Releases 发布。

## 功能概览

- **商品规则**：设置饰品与最高购买价，管理多个规则。
- **购买模式**：模拟购买与 API 下单；实际可用功能以发布版本和账户权限为准。
- **账户与订单**：读取余额、刷新订单，按类型和状态筛选。
- **购买记录**：查看购买时间、价格及平均购买价。
- **运行日志**：区分成功、失败及待确认结果，支持手动清理。
- **深色界面**：账户、订单和运行信息集中展示。

## 下载与使用

1. 发布后前往 [Releases](https://github.com/Xiazhi-Shought/C5-Hunter/releases) 下载完整 Windows 程序包。
2. 解压到独立文件夹，保留随包提供的运行依赖。
3. 根据发布说明配置 C5 AppKey、IP 白名单及收货 Steam 账号。API 购买需具备相应权限。
4. 先使用模拟购买核对规则；真实购买前确认账号、交易链接与价格上限。

详细系统要求、截图及操作说明将在首个版本发布时补充。
